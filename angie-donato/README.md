# Aperturas — Angie Donato

Presentación HTML autónoma para los cuatro temas sorteables del curso de Optimización.

## Abrir
- Archivo: `angie-donato/index.html`.
- En GitHub, descárgalo o ábrelo mediante un servidor local. También puedes abrir el archivo directamente en Chrome.
- No requiere librerías, conexiones externas ni instalación.

## Para exponer
- Botones A–D: elegir Búsqueda Local, Búsqueda Tabú, Algoritmo Genético o Colonia de Hormigas.
- Cada tema tiene **tres diapositivas** para una apertura de aproximadamente **tres minutos**.
- Flechas izquierda/derecha: cambiar diapositiva.
- Teclas 1–4: cambiar de tema.
- N: mostrar u ocultar notas de estudio fuera de la diapositiva.
- F: activar o salir de pantalla completa (según navegador).
- Al concluir la diapositiva 3, dar paso a Angie Loango.

## Criterios y coordinación
- Apertura de Angie Donato: fundamentos conceptuales, origen, inspiración y clasificación (3 minutos).
- Angie Loango: componentes y pseudocódigo (4 minutos).
- Andrés: ejercicio numérico en vivo (4,5 minutos), **aún sin archivo incorporado**.
- Carolina: análisis crítico (2,5 minutos), disponible en `../index.html`.

Se conserva el mismo problema de agente viajero de cinco ciudades del guion del equipo.
Los contenidos de apertura siguen el guion del 15 de noviembre de 2026 y la rúbrica del profesor, con una precisión: el método símplex es exacto para programación lineal, pero no resuelve directamente el problema del agente viajero.

## Estructura actual del proyecto
- `index.html`: contexto común, análisis crítico de Carolina, comparación y preguntas.
- `angie-loango/Angie_Loango_Presentacion.html`: diapositivas de componentes y pseudocódigo.
- `angie-donato/index.html`: aperturas y notas de ensayo.
